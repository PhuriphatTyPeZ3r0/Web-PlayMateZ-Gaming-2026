## <img src="https://api.iconify.design/material-symbols:overview-key-outline.svg?color=%230284C7" width="22" height="22" align="center" /> 1. ภาพรวมโครงงาน (Project Overview)

**PlayMateZ** คือเว็บแพลตฟอร์มที่พัฒนาขึ้นเพื่อตอบโจทย์ปัญหาการเล่นเกมคนเดียว (Solo Queue) หรือการพบเจอกลุ่มผู้เล่นที่มีพฤติกรรม Toxic แพลตฟอร์มนี้เป็นตัวกลางเชื่อมโยงระหว่างผู้เล่นทั่วไปกับผู้เล่นคู่หู ("PlayMate") ที่มีทัศนคติเชิงบวก ทั้งในระดับเล่นผ่อนคลาย (Casual), นักแข่งช่วยไต่แรงก์ (Pro Player Coaching), ไปจนถึงบุคคลมีชื่อเสียง (Celebrity)

โครงงานนี้มุ่งเน้นการฝึกฝนการพัฒนา **Front-End Responsive Web Application** โดยใช้ **Bootstrap 5 Grid System** ร่วมกับ **Vanilla JavaScript** เพื่อควบคุมระบบ Interactive ต่างๆ เช่น การจำลองระบบจองเวลา (Booking Simulation) และการโหลดเนื้อหาแบบ Dynamic

---

## <img src="https://api.iconify.design/material-symbols:featured-seasonal-and-gifts-outline.svg?color=%2310B981" width="22" height="22" align="center" /> 2. ฟังก์ชันเด่นของระบบ (Core Features)

- <img src="https://api.iconify.design/material-symbols:grid-view-outline.svg?color=%238B5CF6" width="18" height="18" align="center" /> **Interactive Game Hub:** แคตตาล็อกเกมยอดนิยม (RoV, Valorant, PUBG, Genshin Impact ฯลฯ) พร้อมฟังก์ชัน "Load More / See More" สลับการแสดงผลแบบ Dynamic
- <img src="https://api.iconify.design/material-symbols:payments-outline.svg?color=%23F59E0B" width="18" height="18" align="center" /> **Tiered Pricing Model:** ระบบแพ็กเกจบริการ 3 ระดับชัดเจน:
  - *Casual Player:* เล่นเพื่อความสนุก ผ่อนคลาย สร้างบรรยากาศที่ดี
  - *Pro Coach:* ติวเทคนิค วิเคราะห์รูปเกม และช่วยแบกไต่แรงก์
  - *Celebrity / VIP:* ประสบการณ์สุดพิเศษกับสตรีมเมอร์หรือผู้เล่นชื่อดัง
- <img src="https://api.iconify.design/material-symbols:edit-calendar-outline.svg?color=%230284C7" width="18" height="18" align="center" /> **Interactive Booking Simulation:** ป็อปอัป Modal สำหรับกรอกข้อมูลจองคิวผู้เล่น (IGN, Discord ID, จำนวนชั่วโมง, เลือกวิธีการชำระเงิน)
- <img src="https://api.iconify.design/material-symbols:palette-outline.svg?color=%23EC4899" width="18" height="18" align="center" /> **Cyberpunk & Gaming Aesthetics:** ดีไซน์โทนสีนีออนม่วง-ดำ (Dark Purple Glow), ไล่เฉดสี Gradient, และการทำ Hover Transitions
- <img src="https://api.iconify.design/material-symbols:devices-outline.svg?color=%2310B981" width="18" height="18" align="center" /> **Mobile-First Responsive Layout:** ปรับเปลี่ยนเลย์เอาต์อัตโนมัติอย่างราบรื่นบนหน้าจอทุกขนาดด้วย Bootstrap 5 Breakpoints

## <img src="https://api.iconify.design/material-symbols:terminal-outline.svg?color=%238B5CF6" width="22" height="22" align="center" /> 3. สถาปัตยกรรมและเทคโนโลยี (Architecture & Tech Stack)

| องค์ประกอบ | เทคโนโลยีที่เลือกใช้ | บทบาทและหน้าที่ภายในโครงงาน |
| :--- | :--- | :--- |
| **Markup** | **HTML5 Semantic** | จัดวางโครงสร้างหน้า Landing Page, ส่วน Hero, Pricing Cards และแบบฟอร์ม |
| **CSS Framework** | **Bootstrap 5.3** | จัดการ Responsive Grid System 12 คอลัมน์, Navbar, Modals และ Utilities |
| **Custom Styling** | **Modern CSS3** | ตัวแปรสี `:root`, นีออนโกลว์เอฟเฟกต์ (Glow Shadows), การปรับแต่ง Card Hover |
| **Client-Side Scripting** | **JavaScript (ES6+)** | การจัดการ Interactive Modals, ตรวจสอบข้อมูล Form Input, สลับปุ่ม Toggle |
| **Icons & Typography** | **FontAwesome & Google Fonts** | ไอคอนควบคุมและฟอนต์ **Kanit** เพื่อการจัดวางที่สวยงามและเป็นระเบียบ |

## <img src="https://api.iconify.design/material-symbols:rocket-launch-outline.svg?color=%230284C7" width="22" height="22" align="center" /> 5. วิธีการติดตั้งและทดสอบ (Local Setup)

โครงงานเป็น Front-End Web สามารถทดสอบการทำงานบนเครื่อง Local ได้ทันที:

1. **โคลนคลังโค้ด:**
   ```bash
   git clone https://github.com/PhuriphatTyPeZ3r0/Web-PlayMateZ-Gaming-2026.git
   cd Web-PlayMateZ-Gaming-2026
   ```

2. **เปิดใช้งานผ่าน Local Development Server (แนะนำ):**
   - เปิดโฟลเดอร์ใน Visual Studio Code
   - คลิกขวาที่ `index.html` แล้วเลือก **Open with Live Server**

3. **หรือเปิดไฟล์โดยตรง:**
   - ดับเบิลคลิกที่ไฟล์ `index.html` เพื่อเปิดทดสอบผ่านเว็บเบราว์เซอร์
